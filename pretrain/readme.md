# Pretrained Weights

Please download the official Segment Anything Model (SAM) pretrained weights and place the file in this folder before running the code.

* **File needed:** `sam_vit_b_01ec64.pth`
* **Download link:** [sam_vit_b_01ec64.pth](https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth)

### Directory Structure Check

After downloading, your folder structure should look exactly like this:

```text
pretrain/
├── README.md
